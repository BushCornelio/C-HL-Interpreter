HOW TO RUN:
1. The interpreter is built using React (JavaScript)
2. Can be run online using StackBlitz or CodeSandbox
3. Or locally using Node.js with Vite/Create React App

ONLINE SETUP (Easiest):
1. Go to https://stackblitz.com/edit/vitejs-vite-react
2. Replace App.jsx content with HLInterpreter.jsx
3. Program runs automatically

LOCAL SETUP:
1. Install Node.js
2. Run: npx create-vite hl-interpreter --template react
3. Run: cd hl-interpreter
4. Run: npm install lucide-react
5. Replace src/App.jsx with HLInterpreter.jsx
6. Run: npm run dev

FEATURES:
- Variable declarations (integer, double)
- Assignment statements
- Mathematical operations (addition, subtraction)
- Output statements
- Conditional statements (if)
- Syntax validation
- Error detection
